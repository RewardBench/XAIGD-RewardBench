# Data

- `annotations/` contains anonymized human preference annotations.
- `camera_real_subset/` contains the released camera-real subset and detector verdicts.
- `dpo/` contains DPO evaluation labels and training-pool metadata.
- `manifests/` contains release manifests.
- `metadata/` contains image identifiers and public schemas.
- `model_outputs/` contains packaged policy-model responses for real and synthetic images.
- `triplets/` contains the clean benchmark and extension triplets.
