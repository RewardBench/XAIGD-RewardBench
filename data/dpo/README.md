# DPO Data

- `internvl_evaluation_labels.json` contains released labels for InternVL DPO evaluation.
- `preference_label_schema.json` defines the released DPO preference-label schema.
- `qwen_candidate_pool_manifest.json` records the Qwen DPO candidate-pool composition.
- `qwen_gpt4o_evaluation_labels.json` contains released labels for Qwen DPO evaluation.
